# 住宅楼与住区内部设施 0.4.0

本版只更新独立 `josm-block-layout.jar`，不修改或替换 BlockFill 0.5.0，也不会覆盖已安装的住宅排布 0.3.1。

## 三步工作流

1. 选中闭合地块生成住宅，按需要手动移动、旋转、调整楼栋。
2. 保持地块选择，勾选“生成内部 service 道路”并开始预览。算法从地块内已存在的住宅 building way 估算主方向，将住宅投影到主轴坐标，按建筑横向位置分排，在相邻排之间找通道。只有道路缓冲完整处于地块内且满足道路宽度、道路到建筑净距的通道才生成。输出 `highway=service + service=driveway + width` way；第一版是一条条直线通道，不自动生成环路、连接公共路口或转弯圆角。
3. 关闭道路生成模式，勾选底商生成。底商带先按沿街后退和进深形成完整多边形，再扣除已有建筑 footprint 与现有 `highway=service` 道路缓冲。差集产生的外环/内环用 `type=multipolygon + building=retail` relation 表示，保留孔洞，不会拿实心 way 覆盖建筑或道路。底商另设“底商到道路退距”。

住宅先生成、手动调整、再生成道路，是半自动流程的重要约束；道路模式不会自动启动或移动住宅。它只根据当前选择地块内已有建筑推算，不创建真实路网连接。请检查道路线端点是否接入地块出入口，并人工清理不合理短段。

## 参数

- service 道路宽度：默认 5 米。
- 道路到建筑退距：默认 3 米，检查中心线两侧道路半宽之外的额外净距。
- 底商沿街后退：默认 6 米。
- 底商进深、高度、30°/45°小倒角沿用现有控件；倒角只削小角，不随进深增长。
- 底商到道路退距：默认 2 米，扣除道路宽度及其两侧附加退距。

每次预览后左键生成，一个 `SequenceCommand` 创建本步骤全部 way/relation，Ctrl+Z 一次撤销。最多 500 个道路/建筑组件。

## 建模限制

简单 service 道路按住宅排间位置估算，不理解消防规范、道路等级、转弯半径、停车或真实出入口需求；道路宽度和退距只是概化布局参数。

底商差集使用 multipolygon outer/inner 环，只有一段底商与某建筑/道路重叠时才在该段切孔或分裂。OSM multipolygon 成员会被 JOSM 作为多个 way 与 relation 管理；上传前请核对标签和关系结构。若底商实际与上层住宅是同一栋混合楼，依旧不应简单叠加独立 `building=retail` 面。

## 验证与更新

`build-layout.ps1` 使用 JOSM 19555 和隔离 JDK 21，编译 `--release 17`。测试覆盖道路排间几何、过窄通道拒绝、建筑/道路差集、multipolygon 环、JOSM 单次撤销和 UI 初始化。

安装 0.4.0 前退出 JOSM，备份当前 `josm-block-layout.jar`，再替换为 `dist\josm-block-layout.jar`。不要改动 `josm-blockfill.jar`。
