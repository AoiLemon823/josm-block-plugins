# 厂房联排与独立住宅预设（2026-11-05）

## 模数核对

未查到厂房整体外轮廓必须为30米倍数的普遍要求。GB/T 50006-2010《厂房建筑模数协调标准》3.0.1的公开条文检索为“厂房建筑的平面和竖向协调模数的基数，宜取扩大模数3M”；基本模数M为100mm，3M为300mm。结构跨度、柱距、构件尺寸和建筑外轮廓应区别处理。插件不将外轮廓强制锁为30m倍数，也不宣称自动规范合规。

## 厂房高度

查询《建筑设计防火规范》GB 50016-2014（2018年版）第3.3节，厂房层数与防火分区面积按生产火灾危险性类别等条件控制；多层工业/非住宅建筑高度大于24米属于高层厂房分类界线之一，但这是分类界线，不是推荐随机高度，也不是一般厂房的统一最高高度。单层高大厂房亦有特殊规定，不能只按24米判定。

《机械工业厂房建筑设计规范》GB 50681-2011只适用于机械工业；高度还受工艺、设备、起重和结构需求影响，不能概括所有工业厂房。目前没有可据以设置全国通用随机上限的统一层数/高度值。

当前参数为独立“厂房标准层高”默认6米、层数范围默认1—2层，每栋独立随机层数，输出 `building:levels` 和 `height=标准层高×层数`，默认结果为6或12米。该默认只是普通低层厂房的地图概化值，不是规范规定。参数可调整；超过24米的多层厂房及具体生产场景应专项复核。OSM `height` 是总高估值，简单相乘未纳入屋面、女儿墙、设备等高度差。

## 厂房同尺寸组团

新增“同尺寸联排最大栋数（0关闭）”，默认3，允许0—10。0或1仅生成单栋；2以上每个候选组随机取1—上限栋。组内长宽相同，沿当前排列长轴依次生成，保留同排间隔。组团长边取用户长度范围上段：max(最小长边,最大长边×0.8)—最大长边，短边保持该排设定值，因此相对更细长；这属于布局偏好，不是规范要求。空间不足、已有建筑阻挡、数量达上限时组团可缩减。固定种子保证复现。

## 住宅独立预设

多层、中高层、高层、自定义分别按savedPreset键持久化。修改住宅参数自动写回当前选项，不跳到自定义。切换选项读取各自参数，自定义独立保存。记忆最近选择项；旧版全局住宅参数迁移至自定义。厂房/底商模式下修改参数不自动覆盖住宅预设。厂房尺寸、间隔、种子、组团上限、标准层高及层数范围均保存并恢复读取。

## 工业 service 道路与界面分组（2026-11-05）

新增可选“同时生成工业 service 通道”。在厂房排间按局部主轴方向识别相邻排，生成单条连续直线候选；要求排间净距足以容纳道宽和两侧建筑退距，检查道路缓冲完全位于地块内、端部不碰建筑。只遍历建筑并排序，复杂度以 O(n log n) 为主，不使用全区域细网格寻路。道路与厂房在同一 SequenceCommand 生成、一次撤销，节点坐标复用。当前不做闭合环路、外部道路连接、转弯半径或消防合规证明。

设置面板拆为“住宅 / 底商 / 工业”页签，方向拾取、提示和预览操作放在页签外统一区域。工业道路默认关闭，宽度默认6米、建筑退距3米。
