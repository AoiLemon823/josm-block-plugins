# 命名系统 0.4.0：样本、思路和使用边界

## 真实地图参考

本次从 OpenStreetMap / Overpass API 查询真实地物，保留对象类型、ID、名称、坐标、原始标签和地图链接。没有逐个使用地图浏览器查看1000处小区或商业体，也没有检查实景、租户或房价。查询结果用于结构分析；不应将它描述为已完成1000处人工实地考察或市场分级。

最初全国矩形查询混入邻国，不能直接使用。正式数据使用20个境内城市/都市圈窗口，再对最初数据中严格落在这些窗口内的记录做补充。深圳窗口跨境部分采用纬度阈值保守排除。窗口不是行政边界，例如广州窗口含佛山等邻近城区；CSV的city_sample表示采样窗口，而不保证地物行政归属。服务器部分请求超时，错误列表保留在manifest.json。

清洗、按完整名称去重并按城市轮询后最终选择：

- 住宅名称500条，来自15个城市窗口。住宅采用有名称的landuse=residential地图对象，含新村、村落、普通小区与商品房等多种结构。
- 商业名称500条，来自20个城市窗口。来源为shop=mall和有名称的retail/commercial区域，再做商场/购物中心等词形筛选。OSM分类仍可能有误标；不能保证每条都是独立购物中心，更不能据名称证明经营档次。
- 每条保留地图对象链接，见research/map-samples/residential-500.csv、commercial-500.csv。
- research/map-samples/sample-atlas.html提供本地可筛选索引，点击名称可打开真实地图对象核查。
- research/map-samples/manifest.json保留数量、获取时间、方法和局限；两个analysis.json保留频次与示例。

住宅样本常见结尾为“园”55、“花园”47、“小区”33、“城”32、“苑”30、“村”19、“家园”12、“新村”9。商业样本常见结尾为“广场”170、“中心”87、“购物中心”36、“百货”22、“商业广场”22。这些是按脚本优先匹配后缀统计，不是严格语言学标注。

## 0.4.0 更新：开发商与商务办公

命名页增加“开发商 / 品牌”文本框。输入华粮房地产开发有限公司会规范化成“华粮”；用户可填写架空开发商而非选现实企业。

- 住宅“城中村 / 村落”和“老社区 / 单位家属院”忽略开发商输入，保留原来的村组、门牌、里弄和单位宿舍风格。
- 刚需、改善和高端住宅可用品牌前缀，生成如“华粮·天誉”、“华粮·云玺台”。
- “社区商业”忽略开发商；中端/高端/奢侈品牌主导商业接受品牌，可生成“景润·千象城”、“景润静海天街”、“景润·都会天地”等品牌格式。候选不重复叠加输入品牌。
- 商务金融用地 0902 新增写字楼、商务中心、高端商务楼宇、总部园区等四个命名风格。名称可带开发商品牌。它们只是名称预设，不意味着官方分类出现了这些三级代码；本次没有新增虚构的090201代码，OSM输出也没有增加未经核实的商业办公 building 标签。
- 0.3参考词库扩充：大量住宅结尾、住宅地景词、社区商业形式、购物中心叫法、写字楼/商务中心/总部园区构词。增加前后缀重复字检查和品牌后缀规范化。
- 每块地创建前的OSM标签确认框已移除。常用标签照常按所选用地类别写入，须在“① 地块与标签”页签和JOSM属性面板核对。属性确认不再弹窗；候选名称的明确选用流程仍保留。已有用地重叠仍会拒绝创建。

## 生成策略

保留用户提出的住宅五档、商业四档，但在界面解释为命名风格，**不是按样本名称自动判断房价、品质或商场品牌档次**。“老破小”在面板改称“老社区 / 单位家属院”，以免把建筑年代与居住品质简单等同；内部等级保持兼容。

每档有多种句式，地名、路名、自然意象、单位名、虚构开发商品牌和结尾按不同概率组合。不再所有名字都以“华某·区名”开头，也不强行把城市名和区名同时塞入名称；城市/区县是可用的上下文。城中村有村名、组、片；老社区有门牌院落、里弄、新村与单位宿舍；刚需项目更多使用家园、花园、新苑；改善项目保留品牌系列、地景短名与雅居/府/庭；豪宅用院、邸、庐等较克制的形式。商业则区分街坊/社区中心、购物中心/百货、城市商业项目、克制短名；去掉“纯奢侈场”就自动写“奢品汇”的直白套路。

词库resources/name-vocabulary.tsv是独立编写的虚构词池，可以编辑后重新构建。华粮、华车、华建等保留用户要求的架空化处理，另加入不同音节的虚构品牌，不强制所有品牌华字开头。输入中的“中国/中粮/中车/中建/中铁”也替换为对应架空形式；不机械替换所有“中”，避免破坏“中山路/中心”等普通词。人工编辑的名称按原文使用。

真实完整名称不作为可抽选的名字：1000条参考名进入只用于否决完全同名的排除表，分隔符和空格归一后比较。当前图层节点、线和关系上的name/name:zh也参与重名检测。预览不占用名字；成功创建才登记，取消或生成失败不会消耗当前确认名称。**无法保证虚构组合在全现实世界从未存在过**；只保证不直接从本次参考表抽取名称，并对已收集样本/已加载图层执行排重。

## 界面流程

在“② 架空名称（OGF）”页签勾选架空命名（默认关闭，保证真实地图编辑不误加虚构名）：

1. 填写架空城市、区县，可填道路，选命名风格。
2. 点“① 生成 / 换一批候选”，列表显示12个可选名称。
3. 单击候选填入待用输入框，可手改；点“② 使用选中名称（下一块）”，或双击候选确认。
4. 状态行明确显示“下一块将使用：…”；地图生成确认框也包含name。
5. 成功创建后清空待用名称；取消/重叠拒绝/失败保留待用名称。
6. 不选定名称、保持待用框为空时，点击地图会逐块自动随机。有待用文字却未确认则提示用户，而不会偷偷换成随机名。

只写入name，新增对象不写name:zh。不批量删除旧数据里的name:zh。仅住宅0701/0703和商业0901（可扩展090101）支持命名，社区公共服务和商务办公不会冒充小区/商场命名。
