# 工业厂房生成与道路功能暂缓

## 当前版本

本版移除道路生成和出口寻路功能，避免在大地块上进行高负荷网格计算造成 JOSM 卡死。完整道路源码与上一版包已保存在 `docs\road-retired-2026-11-05\`，当前 `src` 和新 JAR 不再包含道路生成入口、`ExitRoadRouter` 或排间道路算法。

## 工业厂房

新增 `FactoryGeometry`，在选中的闭合工业地块内生成可变尺度矩形厂房：

- 厂房长、短边分别按最小值/最大值范围随机变化，不再所有楼栋等大。
- 使用固定随机种子，预览和确认结果一致；修改种子可获得另一组可复现布局。
- 支持拾取地块边方向；未设置时使用默认坐标方向。
- 处理地块退界、同排间隔、排间参考间隔、已有 building 避让和 500 栋上限。
- 输出 `building=industrial`，高度与层数沿用当前厂房模式的高度设置。

默认值是概化工业园区布局参数：短边 12—24 米、长边 30—60 米、地块退界 8 米、同排间隔 8 米、排间参考间隔 15 米。它们参考工业园区常见的运输/消防组织思路，但不构成 GB 50016、GB 55037、地方工业用地控制指标或消防审查的自动合规判断。甲乙丙丁戊类生产危险性、耐火等级、消防车道转弯半径、装卸场地、行政生活设施比例等均未建模。

## 城中村暂缓

后续可在 `landuse=residential` 多边形内沿已有道路缓冲生成 3—6 层小型住宅块，但需要先解决：道路识别与道路边界输入、沿街首排退距、巷道最小宽度、随机块之间的可达性、既有建筑避让和多地块连片。当前不实现，避免把随机小块误当成真实城中村路网。

## 验证

`build-layout.ps1` 已通过几何、JOSM `SequenceCommand` 单次撤销和 UI 启动测试。工业厂房测试覆盖：可生成、尺寸变化、固定种子复现、选定方向旋转生成。
